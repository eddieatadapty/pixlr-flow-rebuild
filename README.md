# Pixlr Growth Audit

**Live → https://eddieatadapty.github.io/pixlr-flow-rebuild/**

Five ideas to turn more Pixlr users into subscribers, each built into a clickable version of Pixlr's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask what they came to make | +10–20% CR to purchase |
| 02 | Let them make something before the price | +10–20% CR to purchase |
| 03 | Spell out the free week | +5–15% trial starts |
| 04 | Make the yearly price add up | +10–15% ARPU, more yearly plans |
| 05 | Offer Plus to people who close the paywall | +5–10% CR to purchase |

Every price, rating and feature comes from Pixlr's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Pixlr. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
